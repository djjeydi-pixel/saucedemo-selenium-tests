# Практическая работа 8. Работа с Selenium WebDriver

Данный проект содержит автоматизированные UI-тесты для веб-сайта [SauceDemo](https://www.saucedemo.com/), написанные на Python с использованием фреймворка `pytest` и библиотеки `Selenium WebDriver`.

## Реализованные тестовые сценарии:

1. **Неуспешная авторизация** (`tests/auth/test_auth.py`)
   - Ввод некорректных учетных данных.
   - Проверка появления соответствующего сообщения об ошибке.

2. **Очистка корзины** (`tests/cart/test_cart.py`)
   - Авторизация на сайте.
   - Добавление товара в корзину.
   - Удаление товара и проверка того, что корзина пуста.
   - Возврат на страницу с товарами.

3. **Успешная покупка** (`tests/purchase/test_purchase.py`)
   - Сквозной сценарий: авторизация, добавление товара, заполнение формы оформления заказа и проверка финального экрана успешной покупки.

## Структура проекта:
- `locators/` — содержит файл `locators.py` с централизованными локаторами (селекторами) для элементов страниц.
- `tests/` — содержит файлы тестов, разделенные по логическим папкам (`auth`, `cart`, `purchase`).
- `conftest.py` — файл с фикстурами `pytest` для инициализации браузера и авторизации.
